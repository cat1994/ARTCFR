# Attribution

This package accompanies *Efficient Last-Iterate Convergence in Regret
Minimization via Adaptive Reward Transformation*, by Hang Ren, Yulin Wu,
Shuhan Qi, Jiajia Zhang, Xiaozhen Sun, Tianzi Ma, and Xuan Wang.

The sequence-form game representations and game generators derive from
[sequence-form-py](https://github.com/cat1994/sequence-form-py), whose source
README credits Christian Kroer and Kevin Waugh as initial authors and
Gabriele Farina as another contributor. Original author comments are retained
in the included modules.

The adaptive RT implementation, paper experiment profiles, historical results,
and reproduction entry points are identified in the accompanying configuration
and provenance files. The numerical algorithms use NumPy and SciPy; figure
generation uses Matplotlib, and PDF checks use pypdf. Those dependencies are installed
separately rather than vendored into this package.

This package retains author identities and does not include unrelated research
projects, local development environments, or private server configuration.
